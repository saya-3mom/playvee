# ホーム画面 仕様書

## 画面の目的

親子連れが公園へ出かける前に、必要な情報を素早く見つけられる入口画面。
「行ってから期待外れ」を防ぐため、検索と情報の鮮度を最優先で表示する。

---

## 表示項目

| 領域 | 項目 | 説明 |
|------|------|------|
| ヘッダー | アプリ名・キャッチ | 「ココミケ」「公園の『知りたかった』が、行く前にわかる。」 |
| 検索 | 検索バー | 公園名・エリアで検索 |
| よく探す条件 | フィルターボタン（2列グリッド） | 駐車場 / おむつ替え台 / 幼児向け遊具 / ピクニック可 / トイレ |
| 最近追加された写真 | 写真カード（横スクロール） | カテゴリ・公園名・設備名・追加日 |
| 近くの公園 | 公園カード（横スクロール・1枚見やすいサイズ） | 名前・距離・鮮度バッジ・特徴タグ |
| 最近確認された設備 | 設備リスト | 設備名・公園名・鮮度色・最終確認日・確認人数 |
| ボトムナビ | メニュー | ホーム / 探す / 投稿 / マイページ |

### 鮮度色（設備単位）

| 色 | 表示 | 意味 |
|----|------|------|
| 🟢 緑 | 7日以内に確認 | 7日以内 |
| 🟡 黄 | 30日以内に確認 | 30日以内 |
| 🟠 橙 | 90日以内に確認 | 90日以内 |
| 🔴 赤 | 半年以上未確認 | 半年以上 |

---

## 操作

| 操作 | 動作 |
|------|------|
| 検索バー入力 | 公園検索画面へ遷移（未実装） |
| フィルターチップタップ | 条件を選択（モックでは見た目切替）→ 検索結果へ（未実装） |
| 公園カードタップ | 公園詳細画面へ遷移（未実装） |
| 「地図で見る」タップ | 地図検索画面へ遷移（未実装） |
| 「もっと見る」タップ | 鮮度順一覧へ遷移（未実装） |
| 最近見た公園タップ | 公園詳細画面へ遷移（未実装） |
| ボトムナビ各項目タップ | 対応画面へ遷移（ホームのみ実装） |

## UI/UX メモ

- 最初に見せるもの: **検索バー** → **よく探す条件** → **最近追加された写真** → **近くの公園**
- サービスの価値「情報の鮮度」を設備単位で色分け・左ボーダー・大きめバッジで表示
- 横スクロールはカード一覧（写真・近くの公園）のみ。ページ全体は overflow 禁止
- レイアウト最大幅 800px 中央配置（スマホ基準 390px）
